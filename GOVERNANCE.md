# CGRX Governance

CGRX is currently a maintainer-led open source project. The maintainer is
responsible for roadmap priority, releases, security handling, repository
permissions, and final decisions when technical consensus cannot be reached.
This model can evolve as repeat contributors assume responsibility.

## Decisions

Small, reversible implementation choices are decided in pull-request review.
Changes to public schemas, architecture, dependencies, privacy boundaries,
supported platforms, or governance begin in a GitHub issue or Discussion with a
clear outcome, alternatives, evidence, and compatibility impact.

The project prefers rough consensus backed by reproducible evidence. When
consensus is not possible, the maintainer records the decision and reasoning in
the public thread. Security and conduct details that could harm people or expose
private repositories remain in the appropriate private channel.

## Contributor roles

Anyone may report problems, improve documentation, propose changes, and submit
pull requests under the contribution contract.

**Triage contributors** are repeat contributors trusted to reproduce reports,
apply labels, identify duplicates, improve issue scope, and guide newcomers.
They do not receive release or security access through the triage role.

**Maintainers** review and merge changes, steward one or more subsystems, uphold
project policies, and participate in roadmap decisions. Release and security
permissions remain separately scoped to need.

There is no numeric contribution quota. Triage and maintainer responsibility is
offered based on repeated sound judgment, respectful collaboration, reliable
follow-through, and demonstrated care for correctness, privacy, and compatibility.
Permissions can be narrowed or removed when responsibility changes or project
policies are repeatedly violated.

## Review service level

The target for a first maintainer response is **two business days**. It is a
response target, not a guarantee of merge or complete review. Contributors
should update the issue if they pause work so tasks do not remain reserved.

## Conflicts and appeals

Disclose conflicts of interest and step away from decisions where impartiality
is doubtful. Technical decisions may be reconsidered in the original public
thread when new reproducible evidence appears. Conduct reports follow
[CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md); security reports follow
[SECURITY.md](SECURITY.md).
